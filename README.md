# GifiPay

Static installable web app (PWA). No build step.

## Deploy to Vercel
**Dashboard:** push this folder to GitHub, then vercel.com/new -> import the repo -> Framework Preset "Other" -> Deploy.
**CLI:** `npm i -g vercel && vercel --prod` from this folder.

## Install on your phone
Open the live URL. Android/Chrome: menu -> Install app. iPhone/Safari: Share -> Add to Home Screen.

## Note
All data is demo/in-memory. Real money, KYC and crypto need a licensed backend.
